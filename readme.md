# Full-Stack Form Management App

Full-stack app with customer/admin authentication, role-based access
control, and a CRUD form submission system with filtering and search.

- **Backend setup, tech stack, and full API documentation:** see [`/server/README.md`](./server/README.md)
- **Frontend setup and page overview:** see [`/client/README.md`](./client/README.md)

## Quick Start
```bash
# Terminal 1 — backend
cd server
npm install
# set up .env from .env.example
npm run dev

# Terminal 2 — frontend
cd client
npm install
# set up .env from .env.example
npm run dev
```

Backend runs on `http://localhost:5000`, frontend on `http://localhost:5173`.
